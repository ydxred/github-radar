A LITTLE FIELD GUIDE

把好项目，慢慢收进来。

榜单联网获取，收藏和历史留在本机。中文解读可选本机 Codex 联网解读或 Qwen 离线推理。GitHub Token 可选。

01 · 从今天开始逛

切换今日、本周、本月和编程语言，读取对应的 GitHub Trending 榜单。顶部搜索与领域标签筛选当前列表；左侧“领域发现”汇集本机已采集的不同周期和语言榜，不局限于当前热门榜。领域根据项目名称和简介推断，一个项目可以属于多个领域，数量不能直接相加；分类可能有遗漏。卡片注明最后收录的来源榜单，收录库不是 GitHub 全站。“新发现”是本机首次收录，并不代表项目刚创建。

02 · 看到喜欢的，先收藏

点击项目右上角的书签，保存项目快照。收藏、浏览记录、笔记和偏好存入这台电脑的数据库，不会给 GitHub 账号点 Star。首次升级会合并旧浏览器数据。每天自动备份，设置里可手动备份或恢复；导出文件不包含 Token。

03 · 读懂数字

Star 是累计收藏数；“本日 / 本周 / 本月新增”来自 GitHub 对应榜单。默认保持官方榜单顺序，不代表投资价值或代码质量。收藏和历史中的数字是保存时的快照。

04 · 网慢时也从容一点

榜单在本机缓存 30 分钟，页面打开时每 30 分钟检查更新，后台按关注范围采集；也可以手动刷新（同一榜单 1 分钟内复用缓存）。网络异常会保留上次成功数据并标明时间。后台采集可在设置中暂停或调整。电脑关机、休眠期间不采集，恢复后读取当前榜单，不补造历史。项目详情使用 GitHub 公开接口，剩余额度可在设置里查看。

05 · 顺手的小功能

按 / 快速搜索，Esc 关闭详情。详情里可以写一条私人笔记、复制克隆地址，或直接打开 GitHub 阅读 README。右上角支持明暗切换。中文速读可选 Codex 联网解读或 Qwen 本机离线推理。Codex 使用现有登录与额度，只接收公开 README；笔记不参与生成。结果可能出错，可点来源核对，生成后会在本机缓存。
